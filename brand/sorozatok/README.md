# Sorozat-bibliák

Egy sorozat = egy visszatérő formátum, amit a néző felismer. Minden sorozatnak saját bibliája van (`<sorozat-slug>.md`, a `_SABLON.md` alapján). A szövegíró és a kreatív rendező a sorozat-résznél elsőként ezt olvassa: **a keret marad, csak a hook és a tartalom cserélődik.**

Mikor érdemes sorozatot indítani: ha egy téma 3 részből legalább 2-ben átment a téma-ellenőrzőponton (`docs/meresi-keretrendszer.md`).
