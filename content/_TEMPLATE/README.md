# Egy videó mappája

| Fájl | Ki írja | Mi ez |
|---|---|---|
| `meta.yaml` | mindenki | állapot és metaadatok |
| `research.md` | researcher | tények, források, szög |
| `script.md` | scriptwriter | koncepció, hookok, narráció, jelenetek, CTA, teleprompter |
| `raw/` | te | saját felvétel (arcos mód) |
| `audio/voiceover.wav` | narrator | TTS hang (faceless mód) |
| `transcript.json` | transcriber | szó szintű időbélyegek |
| `edit.json` | editor | vágási lista (arcos mód) |
| `composition/` | motion-designer | HyperFrames projekt |
| `final/` | render + packager | `final.mp4`, `hook-B.mp4`, `cover.png` |
| `post.md` | packager | poszt szöveg, hashtagek, posztolási checklist |
| `metrics.md` | analyst | nézettség, megtartás, követés |
